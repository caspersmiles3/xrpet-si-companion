# XRPet SI Companion™ — Product Blueprint

## Promise
**A living friend from the XRP Ledger.** XRPet turns raw XRPL activity and reliable Ripple/XRP ecosystem updates into a small, useful, entertaining daily companion.

## Design constraint
The product must remain useful in 30 seconds and should not require the creator to manually produce content every day.

## Four cores
### 1. Companion Core
Personality, mood, short conversations, streaks, tiny missions, evolution.

### 2. XRPL Live Core
WebSocket subscription to validated ledgers, server state, fees, and optionally a public account address.

### 3. Ripple Intelligence Core
Ingest primary-source Ripple and XRPL updates, deduplicate, rank, summarize, and present only meaningful changes.

### 4. Truth Engine
Labels claims:
- CONFIRMED: supported by primary source / ledger data.
- LIKELY: well-supported but not yet primary-confirmed.
- SPECULATION: inference or forecast.
- RUMOR: circulating claim without reliable confirmation.
- MISLEADING: materially conflicts with available primary evidence.

8. Settings / notification intensity / explanation level

## User loop
Open → see XRPet mood → 20-second catch-up → optional mission/chat → leave.

## Companion evolution
Drop → Ripple → Wave → Surge → Nexus → Titan → Legend

Evolution is driven by engagement and learning, not by investment size.

## Notification philosophy
Default: quiet. Notify only for user-selected high-value events such as:
- watched-account transaction
- major Ripple announcement
- important XRPL amendment activation
- network incident
- user-requested price threshold (future module)

## Wallet safety
Read/watch public addresses only in the MVP. Any transaction signing belongs in a reputable wallet handoff. Never collect seed phrases or private keys.

## Monetization later
Cosmetics, room themes, companion variants, seasonal packs, premium intelligence filters. No proprietary token required.

## Non-goals
- investment adviser
- price-pump mechanism
- exchange
- custody provider
- replacement for Ripple or XRPL infrastructure
